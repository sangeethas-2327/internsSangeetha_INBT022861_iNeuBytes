## 🎯 Objective
Develop a modern, accessible, responsive clinic landing page for **CareNova Health**. The page provides visitors with essential clinical information, medical services, doctor profiles, patient testimonials, contact details, Google Maps integration, and an interactive appointment enquiry form with client-side JavaScript validation.

---

## 🛠️ Technology Stack
- **HTML5:** Semantic markup structure (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Custom responsive layout, CSS grid, flexbox, CareNova visual theme, animations, and media queries.
- **JavaScript (Vanilla ES6+):** Dynamic form validation, smooth navigation scrolling, and mobile responsive menu toggling.

## 🌟 Key Features
1. **Responsive Navbar:** Sticky header with logo, navigation links, call-to-action button, and mobile hamburger menu.
2. **Hero Section:** Engaging headline, key metrics, and primary CTA to book an enquiry.
3. **About Clinic:** Core mission, accreditation highlights, and clinical values.
4. **Medical Services Grid:** Cards detailing Cardiology, Neurology, Pediatrics, Orthopedics, Dermatology, and Emergency Care.
5. **Why Choose Us:** Highlights of 24/7 care, experienced specialists, state-of-the-art tech, and patient-first approach.
6. **Doctor Highlights:** Profiles of senior specialists with qualifications and departments.
7. **Patient Testimonials:** Clean feedback card carousel / grid.
8. **Interactive Appointment Enquiry Form:** Real-time JavaScript validation for name, email, phone number, department selection, and message.
9. **Contact & Location:** Contact details, working hours, and embedded Google Maps view.
10. **Footer:** Quick links, legal disclaimers, and copyright notice.
